# 조요피 (joyopi) - 프로젝트 정의서

## 1. 프로젝트 개요
- **목표**: 조요피(JOYOPI)가 만드는 모바일 앱의 공식 웹사이트(개발사 사이트). 대표 메뉴는 앱·소개·소식·지원·문의이고, 앱마다 스토어 제출에 필요한 공개 페이지(개인정보 처리방침·지원·계정 삭제 안내)를 둔다. (2026-11-12 전면 개편, 이전 이름 「조요피 연구소」)
- **말투**: 사이트 문구에서 조요피는 회사·개발사가 아니라 **사람**(온라인 활동명)으로 소개한다. 홈·소개·지원 등은 1인칭(「저는」, 「제가」)으로 쓴다. 개인정보 처리방침 같은 법적 문서와 푸터의 사업자 정보는 상호·대표자 표기를 그대로 둔다.
- **핵심 가치**: 로그인 없이 누구나 읽히는 공개 문서, **사이트가 개인정보를 받지 않는 것**(회원가입·로그인·게시판 없음), 철저한 예외 처리.

## 2. 서비스 아키텍처
- **Static-First**: 홈·앱·소개·소식·지원·약관·정책 페이지는 DB 없이 그리는 정적 내용(상수 파일). 앱 문서는 공통 틀(`app/apps/_components/doc-page.tsx`), 안내 페이지는 `app/components/page-shell.tsx`에 내용만 바꿔 넣는다.
- **문의는 메일로**: 공개 게시판 없이 `hello@joyopi.com`으로 받고, 반복되는 질문은 앱별 지원 페이지의 자주 묻는 질문에 적는다.
- **Connection Efficiency**: Next.js HMR 환경에서의 DB 커넥션 누수를 방지하는 싱글톤 패턴 적용.

## 3. 기술 스택
- **Framework**: Next.js 15 (App Router, React 19)
- **Database**: Supabase (PostgreSQL) + Drizzle ORM — 에코 로그(`echo_logs`)만 쓴다.
- **Realtime**: Supabase Realtime (에코)
- **Auth·Storage**: 쓰지 않는다 (2026-11-12 제거).
- **Styling**: Tailwind CSS (Compact/Minimize UI)
- **Logic**: Server Actions (에코 로그)

## 4. 핵심 기능 명세

### 4.1. 회원·로그인 없음 (2026-11-12)
- 사이트에는 **회원가입·로그인·프로필·문의 게시판이 없고, 개인정보를 받지 않는다.** 구글 로그인, 프로필(`/profile`), 회원 탈퇴, 문의 게시판(`/board`)과 사진 업로드를 모두 제거했다.
- 문의는 메일(`hello@joyopi.com`)로 받는다. 안내는 지원(`/support`)과 홈에 있다.
- 예전 주소 `/board`, `/board/...`, `/profile`은 `/support`로 보낸다(`next.config.ts`).

### 4.2. 사이트 구성 (대표 메뉴·헤더·푸터)
- **헤더**: 로고(홈), 대표 메뉴 **앱 · 소개 · 소식 · 지원**(`app/components/site-links.ts`), 언어 전환(한국어 · 日本語 · English). 로그인은 없다. 좁은 화면에서는 메뉴 버튼으로 펼친다(`site-nav.tsx`).
- **푸터**(모든 페이지, `site-footer.tsx`): 대표 메뉴, 약관·정책 링크, **사업자 정보**(페이지 언어로).
- **언어**: 앱 관련 페이지는 `/ko`·`/ja`·`/en` 언어 경로, 나머지는 한국어만. 언어 없는 예전 주소는 브라우저 언어로 보낸다. 규칙은 [03_앱_스토어_페이지.md](./03_앱_스토어_페이지.md) 10장.
- **페이지**: 홈 `/{lang}` · 앱 `/{lang}/apps`, `/{lang}/apps/{rockgazing,agirok}` · 소개 `/about` · 소식 `/news`(`app/(korean)/news/_lib/news.ts`에 글을 더한다) · 지원 `/support`(문의 방법 포함) · 약관·정책 `/policies`.
- **에코(`/echo`)는 메뉴·푸터 어디에도 링크가 없다.** 주소를 아는 사람은 로그인 없이 누구나 쓰며 검색엔진에 나오지 않게 `noindex`로 둔다(4.4).

### 4.2.1. 앱 스토어용 페이지 (`/apps/...`)
- 상세 내용은 [앱 스토어용 페이지 작업 문서 (03_앱_스토어_페이지.md)](./03_앱_스토어_페이지.md)를 참조하십시오.
- **앱 소개**: `/{lang}/apps`(목록), `/{lang}/apps/rockgazing`, `/{lang}/apps/agirok`. 스토어에 등록한 언어 없는 주소(`/apps/...`)도 그대로 열린다(언어 리다이렉트).
- **앱 문서**: `/{lang}/apps/rockgazing/{privacy,support}`, `/{lang}/apps/agirok/{privacy,support,delete-account}`(아기록 처리방침의 ja·en은 번역 준비 중).
- 게시글 3단 대시보드(최근 소식·인기 게시글·활발한 논의)는 2026-11-12 제거.

### 4.3. 문의 게시판 — 제거 (2026-11-12)
- 공개 게시판은 문의에 맞지 않아(개인정보가 섞이기 쉽고, 글 하나 쓰려고 로그인해야 함) 없앴다. 4.1 참조.

### 4.4. 메아리 (Echo - `/echo`, 로그인 없이 공개, 메뉴에 없음)
- 상세 내용은 [메아리 상세 기능 명세 (02_메아리.md)](./02_메아리.md)를 참조하십시오.
- **주요 특징**: Supabase Realtime을 활용한 초저지연 비언어적 실시간 소통 실험 서비스.

### 4.5. 공통 UX/UI 가이드라인
- **컴포넌트 시스템**:
- **Next.js Image 최적화**: 
  - 모든 이미지는 `next/image`를 사용하며, 부모 요소의 `relative` 배치와 명시적인 `sizes` 프롭 지정을 통해 LCP 성능과 레이아웃 안정성 확보.
- **커스텀 다이얼로그**: 브라우저 기본 `alert/confirm`을 배제하고 디자인 테마와 일치된 전역 모달 시스템(`DialogProvider`) 사용.
- **방어적 UI**: 모든 입력창에 `maxLength`를 강제하여 한도 초과 입력을 원천 차단하고, 초과 시 제출 버튼 비활성화.
 
## 5. 로드맵
- **1단계 (기반 구축 - 완료)**: 통합 인증 및 프로필 시스템 확립.
- **2단계 (커뮤니티 고도화 - 완료)**: 피드형 게시판, 인라인 편집, 대시보드 집계, 모달 프리뷰, 전역 다이얼로그 시스템 구축.
- **3단계 (인프라 및 UX 확장 - 완료)**: 무한 스크롤 도입, 프로필/게시글 사진 시스템(리사이징 및 최적화 포함) 구축, 디자인 시스템 고도화(FAB, Identity Bar).
- **4단계 (서비스 다각화 - 진행 중)**: '메아리(Echo)' 실시간 멀티플레이 실험 서비스 공개. (오버워치 카운터 맵은 2026-11 제거)
- **5단계 (기능 정리 - 2026-10-17)**: 돼지 일기·심장을 바쳐라·밈챗·아기 이름 랭킹 서비스를 종료하고 코드와 문서를 삭제.
- **6단계 (개발사 공식 사이트로 전면 개편 - 2026-11-12)**: 홈을 앱 중심으로 바꾸고 대표 메뉴(앱·소개·소식·지원·문의)와 공통 푸터, 앱별 소개·개인정보 처리방침·지원·계정 삭제 안내 페이지를 추가. 자유게시판을 문의 게시판으로 전환, 에코를 메뉴에서 제거. 사이트 이름을 「조요피 연구소」에서 「조요피」로 변경.
- **7단계 (회원·게시판 제거 - 2026-11-12)**: 프로필을 최소화한 뒤 문의 게시판·구글 로그인·프로필·회원 탈퇴를 모두 없애 사이트가 개인정보를 받지 않게 함. 문의는 메일로 받고, 에코는 로그인 없이 공개.
