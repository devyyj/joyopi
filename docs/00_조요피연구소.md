# 조요피 (joyopi) - 프로젝트 정의서

## 1. 프로젝트 개요
- **목표**: 조요피(JOYOPI)가 만드는 모바일 앱의 공식 웹사이트(개발사 사이트). 대표 메뉴는 앱·소개·소식·지원·문의이고, 앱마다 스토어 제출에 필요한 공개 페이지(개인정보 처리방침·지원·계정 삭제 안내)를 둔다. (2026-11-12 전면 개편, 이전 이름 「조요피 연구소」)
- **말투**: 사이트 문구에서 조요피는 회사·개발사가 아니라 **사람**(온라인 활동명)으로 소개한다. 홈·소개·지원 등은 1인칭(「저는」, 「제가」)으로 쓴다. 개인정보 처리방침 같은 법적 문서와 푸터의 사업자 정보는 상호·대표자 표기를 그대로 둔다.
- **핵심 가치**: 로그인 없이 누구나 읽히는 공개 문서, 즉각적인 반응성(Optimistic UI), 철저한 예외 처리와 안전한 보안 체계.

## 2. 서비스 아키텍처
- **Static-First**: 홈·앱·소개·소식·지원·약관·정책 페이지는 DB 없이 그리는 정적 내용(상수 파일). 앱 문서는 공통 틀(`app/apps/_components/doc-page.tsx`), 안내 페이지는 `app/components/page-shell.tsx`에 내용만 바꿔 넣는다.
- **Modal-Based Interaction**: 상세 조회 시 페이지 이동 없이 모달을 통해 데이터를 즉시 로드.
- **Feed-Style Board**: 문의 게시판 목록에서 본문과 댓글(답변)이 바로 보이는 피드 형태.
- **Connection Efficiency**: Next.js HMR 환경에서의 DB 커넥션 누수를 방지하는 싱글톤 패턴 적용.

## 3. 기술 스택
- **Framework**: Next.js 15 (App Router, React 19)
- **Database**: Supabase (PostgreSQL) + Drizzle ORM
- **Storage**: Supabase Storage (Profile Avatars, Post Images)
- **Auth**: Supabase Auth (Google OAuth)
- **Styling**: Tailwind CSS (Compact/Minimize UI)
- **Logic**: Server Actions + useOptimistic + Context API (Dialog System)
- **Optimization**: Native Intersection Observer (Infinite Scroll), Client-side Canvas Resizing, Next.js Image Optimization (LCP)

## 4. 핵심 기능 명세

### 4.1. 통합 인증 및 프로필
- **익명성 보장**: 첫 로그인 시 임의의 닉네임 부여 및 이메일 비노출.
- **프로필 관리**: 
  - **아바타(프로필 사진)**: 
    - 사진 업로드 및 변경 기능 지원.
    - 서버 저장 용량 및 전송 대역폭 최적화를 위해 클라이언트 측에서 `Canvas`를 이용해 **300x300 크기의 WebP** 형식으로 자동 리사이징 후 업로드.
    - 이미지 로드 실패 시 사용자의 닉네임 첫 글자를 활용한 **이니셜 아바타**로 자동 폴백.
  - **자기소개**: 닉네임(최대 10자) 및 한줄 자기소개(최대 100자) 설정.
  - **입력 제한**: 입력 시 실시간 글자 수 카운터 및 초과 방지(`maxLength`) 적용.
- **안전한 탈퇴**: 
  - Edge Functions를 통한 계정 정보 및 소셜 연동 해제.
  - **데이터 정책**: 탈퇴 시 개인정보 및 프로필은 즉시 삭제되나, 작성한 게시글/댓글은 사이트 운영을 위해 유지됨(작성자 정보는 익명화 처리).

### 4.2. 사이트 구성 (대표 메뉴·헤더·푸터)
- **헤더**: 로고(홈), 대표 메뉴 **앱 · 소개 · 소식 · 지원 · 문의**(`app/components/site-links.ts`), 로그인. 좁은 화면에서는 메뉴 버튼으로 펼친다(`site-nav.tsx`).
- **푸터**(모든 페이지, `site-footer.tsx`): 대표 메뉴, 약관·정책 링크, **사업자 정보**.
- **페이지**: 홈 `/` · 앱 `/apps`, `/apps/{rockgazing,agirok}` · 소개 `/about` · 소식 `/news`(`app/news/_lib/news.ts`에 글을 더한다) · 지원 `/support` · 문의 `/board` · 약관·정책 `/policies`.
- **에코(`/echo`)는 메뉴·푸터 어디에도 링크가 없다.** 주소를 아는 허용 계정만 직접 들어가며 검색엔진에 나오지 않게 `noindex`로 둔다(4.4).

### 4.2.1. 앱 스토어용 페이지 (`/apps/...`)
- 상세 내용은 [앱 스토어용 페이지 작업 문서 (03_앱_스토어_페이지.md)](./03_앱_스토어_페이지.md)를 참조하십시오.
- **앱 소개**: `/apps`(목록), `/apps/rockgazing`, `/apps/agirok`.
- **앱 문서**: `/apps/rockgazing/{privacy,support}`(ko/en/ja), `/apps/agirok/{privacy,support,delete-account}`(ko).
- 게시글 3단 대시보드(최근 소식·인기 게시글·활발한 논의)는 2026-11-12 제거.

### 4.3. 문의 게시판 (`/board`, 이전 이름 자유게시판)
- 상세 내용은 [자유게시판 정의서 (01_자유게시판.md)](./01_자유게시판.md)를 참조하십시오.
- **주요 특징**: 피드형 레이아웃, 무한 스크롤, 멀티미디어 업로드, 인라인 편집 지원.

### 4.4. 메아리 (Echo - `/echo`, 허용 계정 전용, 메뉴에 없음)
- 상세 내용은 [메아리 상세 기능 명세 (02_메아리.md)](./02_메아리.md)를 참조하십시오.
- **주요 특징**: Supabase Realtime을 활용한 초저지연 비언어적 실시간 소통 실험 서비스.

### 4.5. 공통 UX/UI 가이드라인
- **컴포넌트 시스템**:
  - **UserAvatar**: 4단계 크기 지원, 이미지 로드 실패 시 이니셜 폴백 내장.
  - **SafeImage**: 시스템 전반의 안전한 이미지 로더. 저장소에 없는 사진 참조 시 깨진 아이콘 대신 **"이미지를 불러올 수 없습니다"** 안내 문구와 전용 아이콘 표시.
  - **UserNickname**: 독립적인 텍스트 링크 형태의 닉네임 컴포넌트.
- **Next.js Image 최적화**: 
  - 모든 이미지는 `next/image`를 사용하며, 부모 요소의 `relative` 배치와 명시적인 `sizes` 프롭 지정을 통해 LCP 성능과 레이아웃 안정성 확보.
- **커스텀 다이얼로그**: 브라우저 기본 `alert/confirm`을 배제하고 디자인 테마와 일치된 전역 모달 시스템(`DialogProvider`) 사용.
- **방어적 UI**: 모든 입력창에 `maxLength`를 강제하여 한도 초과 입력을 원천 차단하고, 초과 시 제출 버튼 비활성화.
 
## 5. 로드맵
- **1단계 (기반 구축 - 완료)**: 통합 인증 및 프로필 시스템 확립.
- **2단계 (커뮤니티 고도화 - 완료)**: 피드형 게시판, 인라인 편집, 대시보드 집계, 모달 프리뷰, 전역 다이얼로그 시스템 구축.
- **3단계 (인프라 및 UX 확장 - 완료)**: 무한 스크롤 도입, 프로필/게시글 사진 시스템(리사이징 및 최적화 포함) 구축, 디자인 시스템 고도화(FAB, Identity Bar).
- **4단계 (서비스 다각화 - 진행 중)**: '메아리(Echo)' 실시간 멀티플레이 실험 서비스 공개. (오버워치 카운터 맵은 2026-11 제거)
- **5단계 (기능 정리 - 2026-10-17)**: 돼지 일기·심장을 바쳐라·밈챗·아기 이름 랭킹 서비스를 종료하고 코드와 문서를 삭제.
- **6단계 (개발사 공식 사이트로 전면 개편 - 2026-11-12)**: 홈을 앱 중심으로 바꾸고 대표 메뉴(앱·소개·소식·지원·문의)와 공통 푸터, 앱별 소개·개인정보 처리방침·지원·계정 삭제 안내 페이지를 추가. 자유게시판을 문의 게시판으로 전환, 에코를 메뉴에서 제거. 사이트 이름을 「조요피 연구소」에서 「조요피」로 변경.
