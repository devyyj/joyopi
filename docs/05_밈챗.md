# [요구사항 명세서] 밈챗(MemeChat): 모션 인식 기반 밈(Meme) 인터랙티브 채팅 서비스

## 1. 개요 (Overview)

**밈챗(MemeChat)**은 사용자의 프라이버시를 보호하면서도 인터넷 밈(Meme)을 통해 유쾌하게 소통하는 실시간 채팅 서비스입니다. 사용자는 카메라를 통해 자신의 동작을 확인하지만, 상대방에게는 실제 얼굴 대신 사용자의 현재 감정이나 동작에 딱 맞는 **'인터넷 밈 이미지'**와 음성만이 공유됩니다.

---

## 2. 핵심 컨셉: "내 얼굴 대신 밈(Meme)"

* **밈 스트리밍**: 사용자가 웃으면 '무한도전'의 유재석 웃는 밈이, 엄지를 올리면 '따봉 도치' 밈이 상대방 화면에 즉시 나타납니다.
* **완벽한 익명성**: 상대방에게는 실제 영상 스트림을 절대 보내지 않으며, 오직 음성과 '밈 이벤트' 데이터만 전송하여 얼굴 노출에 대한 부담을 0%로 만듭니다.

---

## 3. 기능 요구사항 (Functional Requirements)

### F-1. 오디오 채팅 및 로컬 밈 프리뷰

* **F-1.1 (로컬 모니터링)**: 사용자는 좌측 하단에 자신의 실제 캠 화면과 현재 자신에게 적용되고 있는 밈 이미지를 동시에 확인합니다.
* **F-1.2 (오디오 중심 WebRTC)**: Supabase Realtime을 시그널링 서버로 활용하여 오디오 스트림만 P2P로 연결합니다.
* **F-1.3 (밈 라이브러리)**: 서비스 내부에 감정/동작별로 매핑된 다양한 밈 이미지셋을 보유합니다.

### F-2. 로컬 모션 인식 및 밈 매핑

* **F-2.1 (동작 감지)**: MediaPipe를 통해 사용자의 표정(Smile, Sad, Surprised)과 손동작(Thumbs Up, Peace, Wave)을 분석합니다.
* **F-2.2 (밈 매칭 엔진)**: 감지된 동작 코드에 따라 미리 정의된 밈 이미지 경로(예: `SMILE` -> `/images/memes/laughing_guy.webp`)를 결정합니다.

### F-3. 실시간 밈 브로드캐스트 (Supabase)

* **F-3.1 (밈 이벤트 전송)**: 사용자의 동작이 변하는 순간, 채널에 접속한 모두에게 밈 정보를 보냅니다.
* **F-3.2 (Presence 상태)**: 누가 현재 대화 중인지, 어떤 밈 상태를 유지하고 있는지 실시간으로 관리합니다.

### F-4. 밈 인터랙션 UI (Framer Motion)

* **F-4.1 (상대방 밈 카드)**: 상대방 영역은 해당 사용자의 밈 이미지가 화면을 가득 채우는 카드로 표시됩니다.
* **F-4.2 (밈 전환 효과)**: 밈이 바뀔 때 '짤'이 터지는 듯한 애니메이션 효과나 사운드 효과를 추가하여 타격감을 높입니다.

## 4. 밈 매핑 설계 (Meme Mapping Example)

| **웃는 표정 (Smile)** | "자지러지는 웃음" 밈 | `MEME_LAUGH` |
| **엄지 척 (Thumbs Up)** | "따봉 도치" 또는 "합격" 밈 | `MEME_GOOD` |
| **슬픈 표정 (Sad)** | "개구리 페페 눈물" 밈 | `MEME_SAD` |
| **놀란 표정 (Surprised)** | "동공지진" 또는 "피카츄 놀람" 밈 | `MEME_SHOCK` |
| **손 흔들기 (Wave)** | "반가워요" 밈 | `MEME_HELLO` |
| **V자 손동작 (Peace)** | "신난다" 또는 "평화" 밈 | `MEME_PEACE` |

## 6. 단계별 개발 계획 (Roadmap)

### Phase 1: 환경 설정 및 기술 검증 (Setup & PoC)
* [ ] MediaPipe Vision 패키지 설치 및 Next.js 연동 환경 구축
* [ ] 브라우저 카메라 권한 획득 및 로컬 비디오 스트림 렌더링 테스트
* [ ] 기본 밈 이미지(Placeholder) 리소스 준비 및 프로젝트 폴더 구조화

### Phase 2: 로컬 모션 인식 엔진 개발 (Motion Engine)
* [ ] `useMotionDetection` 커스텀 훅 개발 (MediaPipe 래핑)
* [ ] 얼굴 표정(Smile, Sad 등) 감지 로직 및 상태 매핑 구현
* [ ] 손동작(Thumbs Up, Wave 등) 감지 로직 구현 및 인식률 최적화

### Phase 3: 실시간 통신 및 시그널링 통합 (Realtime & WebRTC)
* [ ] Supabase Realtime을 이용한 `MOTION_ACTION` 브로드캐스트 구현
* [ ] WebRTC 오디오 전용 스트림 연결 (Audio-only PeerConnection)
* [ ] Presence를 이용한 방 참여자 목록 및 상태 동기화

### Phase 4: 밈 채팅 UI/UX 고도화 (Frontend)
* [ ] `MemeCard` 컴포넌트 개발 (Framer Motion 애니메이션 적용)
* [ ] 내 캠 화면(로컬 프리뷰) 및 현재 적용 밈 레이아웃 구현
* [ ] 밈 전환 시 타격감 있는 시각 효과 및 사운드 효과 추가

### Phase 5: 최적화 및 안정화 (Optimization)
* [ ] CPU 점유율 최적화 (프레임 드랍 조절, requestAnimationFrame 활용)
* [ ] 모바일 브라우저 호환성 및 네트워크 저지연 테스트
* [ ] Vercel/Supabase 환경 최종 배포 및 프라이버시 보안 점검
