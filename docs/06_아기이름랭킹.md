# 06. 아기 이름 랭킹 (Baby Name Ranker)

이 문서는 곧 출산할 아이의 이름을 아빠와 엄마가 함께 고민하고, 각자가 선호하는 이름의 순위를 관리하며 서로의 의견을 조율할 수 있는 **'아기 이름 랭킹'** 서비스의 기능 정의서입니다.

---

## 1. 개요 및 목적
- **목적**: 아이의 이름을 오랫동안 신중하게 고민하고, 아빠와 엄마 각자가 원하는 이름의 우선순위를 시각적으로 확인하며 조율하기 위함입니다.
- **주요 가치**:
  - 부모가 각자 생각하는 후보 이름 목록을 독립적으로 관리할 수 있습니다.
  - 이름의 추가, 수정, 삭제(CRUD) 및 순서 변경(우선순위 조정)이 직관적으로 가능합니다.
  - 아빠와 엄마의 선호도 랭킹을 한 화면에서 좌우로 대비하여 보여줌으로써, 겹치는 이름이나 선호도의 차이를 쉽게 발견할 수 있습니다.

---

## 2. 화면 구성 (UI/UX)
화면은 반응형 2열 레이아웃(Desktop 기준 좌우 분할, Mobile 기준 상하 배치)으로 구성됩니다.

```
+-----------------------------------------------------------+
|                        아기 이름 랭킹                       |
+-----------------------------+-----------------------------+
|        👨 아빠의 랭킹        |        👩 엄마의 랭킹        |
| [이름 추가 버튼]            | [이름 추가 버튼]            |
+-----------------------------+-----------------------------+
| 1. 우주 (★)                 | 1. 서하 (★)                 |
| 2. 서하 (★)                 | 2. 우주 (★)                 |
| 3. 도윤                     | 3. 지안                     |
| ...                         | ...                         |
+-----------------------------+-----------------------------+
```

### 2.1. 좌측 열: 아빠의 이름 랭킹 (Role: `dad`)
- 아빠가 등록한 아기 이름 후보들이 순위(1위부터 차례대로) 순서로 표시됩니다.
- 신규 이름 후보 추가 버튼이 제공됩니다.
- 각 아이템에는 순위 변경(드래그 앤 드롭 혹은 위/아래 이동 버튼), 수정, 삭제 기능이 제공됩니다.

### 2.2. 우측 열: 엄마의 랭킹 (Role: `mom`)
- 엄마가 등록한 아기 이름 후보들이 순위 순서로 표시됩니다.
- 아빠 영역과 대칭되는 인터페이스를 제공합니다.

### 2.3. 공통 및 특수 효과
- **일치(Match) 표시**: 아빠와 엄마 모두의 목록에 공통으로 존재하는 이름은 하이라이트(예: 별표 표시 또는 배경색 변경) 처리하여 두 사람 모두의 관심 목록에 있음을 알립니다.

---

## 3. 기능 상세 정의

### 3.1. 이름 CRUD (Create, Read, Update, Delete)
- **등록 (Create)**:
  - 아빠 영역 또는 엄마 영역에서 이름 후보를 입력하여 추가합니다.
  - 추가된 이름은 해당 영역의 가장 마지막 순위로 자동 배정됩니다.
- **조회 (Read)**:
  - 데이터베이스에서 `role` (dad / mom)별로 목록을 조회한 후, `rank` (순위) 오름차순으로 정렬하여 표시합니다.
- **수정 (Update)**:
  - 이름 후보명 자체를 변경할 수 있는 인라인 편집 또는 모달 창을 지원합니다.
- **삭제 (Delete)**:
  - 후보에서 제외하고 싶은 이름을 삭제합니다. 삭제 시 하위 순위의 항목들이 자동으로 순위가 앞으로 당겨집니다.

### 3.2. 순서 변경 (Reordering)
- **우선순위 조정**:
  - 드래그 앤 드롭(Drag and Drop) 라이브러리(예: `@hello-pangea/dnd` 또는 `@dnd-kit`)를 사용하거나, 항목별 위/아래 이동 버튼(▲/▼)을 통해 순위를 실시간으로 조정할 수 있습니다.
  - 순위가 변경되면 서버 액션(Server Action)을 통해 해당 역할(`role`)을 가진 모든 이름 목록의 `rank` 컬럼 값이 일괄 갱신됩니다.

### 3.3. 권한 제어 (Admin 전용)
- **페이지 접근 제한**:
  - 아기 이름 랭킹 페이지(예: `/baby-names`)는 관리자(`admin`) 권한이 있는 세션만 접근할 수 있습니다.
  - 관리자가 아닌 사용자가 접근 시, 로그인 페이지 또는 권한 부족 안내 페이지(`/unauthorized`)로 리다이렉트합니다.
- **서버 액션 보안**:
  - 이름 CRUD 및 Reordering을 처리하는 모든 서버 액션은 내부적으로 현재 세션 유저의 역할(Role)이 `admin`인지 검증하는 단계를 포함합니다.
  - 권한이 없는 요청일 경우 즉시 에러(`Unauthorized`)를 반환합니다.

## 4. 데이터베이스 및 스키마 설계 (Drizzle ORM 예시)

아이 이름 정보를 저장할 `baby_names` 테이블을 설계합니다.

```typescript
import { pgTable, uuid, varchar, integer, timestamp } from "drizzle-orm/pg-core";

export const babyNames = pgTable("baby_names", {
  id: uuid("id").primaryKey().defaultRandom(),
  name: varchar("name", { length: 50 }).notNull(),
  role: varchar("role", { length: 10 }).notNull(), // 'dad' | 'mom'
  rank: integer("rank").notNull(),                 // 1부터 시작하는 순위
  createdAt: timestamp("created_at").defaultNow().notNull(),
  updatedAt: timestamp("updated_at").defaultNow().notNull(),
});
```

### 4.1. 정렬 기준 및 제약 조건
- 특정 `role` 그룹 내에서 `rank`는 1부터 시작하여 연속된 정수를 가져야 합니다.
- 정렬 쿼리 예시:
  ```typescript
  db.select().from(babyNames).where(eq(babyNames.role, 'dad')).orderBy(asc(babyNames.rank))
  ```

## 5. 단계별 구현 계획

1. **데이터베이스 마이그레이션**:
   - `db/schema.ts`에 `babyNames` 테이블 정의를 추가하고 Drizzle 마이그레이션을 생성 및 적용합니다.
2. **서버 액션(Server Actions) 구현**:
   - 모든 서버 액션 수행 전 호출자의 관리자(`admin`) 권한 여부를 체크하는 공통 유틸함수(`verifyAdmin`)를 설계 및 적용합니다.
   - `getBabyNames(role)`: 특정 성별/역할의 이름 목록 조회 (관리자 세션 검증)
   - `createBabyName(name, role)`: 이름 추가 및 초기 rank 부여 (관리자 세션 검증)
   - `updateBabyName(id, name)`: 이름 텍스트 변경 (관리자 세션 검증)
   - `deleteBabyName(id)`: 이름 삭제 및 나머지 순위 재조정 (관리자 세션 검증)
   - `reorderBabyNames(role, orderedIds)`: 드래그 앤 드롭 또는 순서 조정 후 전체 순서 저장 (관리자 세션 검증)
3. **권한 제어 및 페이지 보호**:
   - 미들웨어 또는 Next.js 15 Server Component의 `layout.tsx` / `page.tsx` 내에서 Supabase Auth 세션 정보를 조회하여, `admin` 역할이 없으면 접근 차단 및 리다이렉트 처리합니다.
4. **컴포넌트 개발**:
   - `BabyNameColumn`: 아빠/엄마 개별 랭킹 컴포넌트
   - `BabyNameItem`: 개별 이름 표시 및 편집/삭제/이동 버튼이 포함된 항목 컴포넌트
   - `BabyNameContainer`: 전체 화면을 아우르며 좌우 랭킹 컬럼을 띄우고 교차 매칭(동일 이름)을 검출해주는 최상위 컴포넌트
5. **리액션 및 피드백 (Aesthetics)**:
   - 이름이 매칭될 때 애니메이션 연출.
   - 드래그할 때 부드러운 움직임 보장.
